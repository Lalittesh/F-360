# 🍽️ FoodSphere 360

### Good Food Deserves Another Table. 🌱✨

**FoodSphere 360** is a MERN stack food donation platform that connects restaurants with NGOs to help redirect surplus food to people and communities in need.

🌐 **Live Demo:** [FoodSphere 360](https://foodsphere360.onrender.com)

## 🍱 Core Workflow

### 🏪 Restaurant

1. Register / Login
2. Select **Restaurant**
3. Add surplus food donation
4. Provide food details and availability
5. View donation status
6. Manage previous donations

### 🏢 NGO

1. Register / Login
2. Select **NGO**
3. Browse available food donations
4. Select suitable food
5. Submit a request
6. Track requested donations

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Lalittesh/F-360.git
cd foodsphere360
```

### 2. Install dependencies

**Frontend:**

```bash
cd client
npm install
```

**Backend:**

```bash
cd ../server
npm install
```

### 3. Configure environment variables

Create a `.env` file inside the `server` folder:

```env
PORT=5000
MONGODB_URI=YOUR_MONGODB_URI
JWT_SECRET=YOUR_JWT_SECRET
```

### 4. Start the backend

```bash
cd server
npm start
```

### 5. Start the frontend

Open another terminal:

```bash
cd client
npm run dev
```

🎉 Open the local URL shown by Vite in your browser.
